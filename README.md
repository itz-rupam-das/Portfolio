# Portfolio

A premium, modern developer portfolio built with React and Vanilla CSS, focusing on a high-end visual experience and performance.

## 🚀 Features

- **Modern UI/UX**: Premium aesthetic with dark/light mode support.
- **Vanilla CSS**: Bespoke styling system without the bloat of heavy frameworks.
- **Responsive Design**: Optimized for all screen sizes, from mobile to desktop.
- **Framer Motion**: Smooth animations and micro-interactions.
- **Supabase Integration**: Designed for backend-driven content and dynamic data.

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite
- **Styling**: Vanilla CSS (Custom Design System)
- **Animations**: Framer Motion
- **Icons**: React Icons
- **Backend (Planned)**: Supabase

## 📦 Getting Started

### Prerequisites

- Node.js (Latest LTS recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/itz-rupam-das/Portfolio.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```
